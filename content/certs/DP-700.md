# DP-700: Implementing Data Engineering Solutions Using Microsoft Fabric – Study Guide

> [!NOTE]
> **CẬP NHẬT NỘI DUNG:** Microsoft đã lên lịch cập nhật nội dung cho kỳ thi DP-700 vào ngày **20/04/2026**. fabric là nền tảng đang phát triển cực nhanh, hãy luôn kiểm tra Skills Measured mới nhất.

Tài liệu tổng hợp kiến thức cho kỳ thi **DP-700** (Microsoft Certified: Fabric Data Engineer Associate). Nội dung tập trung vào việc thiết kế, triển khai và quản lý các giải pháp data engineering trên nền tảng Microsoft Fabric.

## 1. Implement & Manage an Analytics Solution (30–35%)

### Fabric Workspace & Governance
- **Workspace settings**: Cấu hình Spark settings, capacity, và quyền truy cập.
- **Lifecycle management**: Triển khai CI/CD với **Deployment Pipelines** và tích hợp **Git** (Azure DevOps/GitHub) cho Fabric items.
- **Security**: 
    - **OneLake Security**: Data access control, sharing.
    - **Workspace Roles**: Admin, Member, Contributor, Viewer.
    - **Row-level security (RLS)** & **Object-level security (OLS)** trong Warehouse và Lakehouse.

### Orchestration (Điều phối)
- **Data Pipelines**: Tạo và quản lý pipeline để di chuyển dữ liệu (Copy activity, Invoke Notebook/Dataflow).
- **Notebooks**: Dùng cho các tác vụ phức tạp bằng PySpark.
- **Scheduling**: Lập lịch chạy cho các item trong Fabric.

---

## 2. Ingest & Transform Data (30–35%)

### Ingestion (Nạp dữ liệu)
- **Dataflows Gen2**: Công cụ low-code (Power Query online) để nạp và transform dữ liệu.
- **OneLake Shortcuts**: Kết nối trực tiếp tới data ở nơi khác (ADLS Gen2, AWS S3, Google Cloud Storage) mà không cần copy dữ liệu.
- **Mirroring**: Tự động đồng bộ dữ liệu từ external DBs (SQL DB, Cosmos DB, Snowflake) vào Fabric OneLake dưới định dạng Delta.

### Transformation (Biến đổi dữ liệu)
- **Lakehouse**: Kết hợp Data Lake và Data Warehouse. Dùng **Spark Notebooks** để ghi vào các bảng Delta.
- **Data Warehouse**: Dùng **T-SQL** để truy vấn và xử lý dữ liệu với hiệu năng cao.
- **Real-Time Intelligence**: 
    - **Eventhouse & KQL Database**: Xử lý dữ liệu streaming với độ trễ thấp.
    - **Eventstreams**: Ingest dữ liệu stream (từ IoT, logs) và định tuyến tới các đích khác nhau.

### Data Quality & Loading Patterns
- **Incremental Loading**: Chỉ load dữ liệu thay đổi để tối ưu thời gian/chi phí.
- **Medallion Architecture**: Tổ chức dữ liệu qua các lớp Bronze (Raw) -> Silver (Cleaned) -> Gold (Aggregated).

---

## 3. Monitor & Optimize an Analytics Solution (30–35%)

### Monitoring
- **Fabric Capacity Metrics App**: Theo dõi lượng compute (CU) tiêu thụ để quản lý chi phí.
- **Monitoring Hub**: Xem trạng thái của tất cả các job (Pipelines, Notebooks, Spark sessions).
- **Spark Advisor**: Nhận các gợi ý tối ưu hóa cho Notebooks.

### Performance Optimization
- **Partitioning**: Chia nhỏ dữ liệu trong Delta tables để query nhanh hơn.
- **V-Order**: Kỹ thuật nén và tối ưu hóa file Parquet của Microsoft Fabric giúp tăng tốc độ đọc dữ liệu lên nhiều lần.
- **Caching**: Hiểu cách Fabric dùng cache cho các truy vấn SQL.
- **Identifying bottlenecks**: Tìm các phần code Spark chậm hoặc các query SQL kém hiệu quả.

---

## Lưu ý chung khi ôn DP-700

1. **V-Order & Delta Lake**: Đây là cốt lõi của Fabric, hãy nắm chắc cách dữ liệu được lưu trữ.
2. **Shortcuts vs Mirroring**: Khi nào thì dùng cái nào? (Shortcuts giữ data tại chỗ, Mirroring copy data theo thời gian thực).
3. **Notebooks vs Dataflows**: Dataflows cho low-code/biến đổi đơn giản, Notebooks cho logic phức tạp và xử lý big data.
4. **Capacity Management**: Hiểu về CU (Capacity Units) và cách "smoothing" hoạt động để không bị nghẽn hệ thống.
